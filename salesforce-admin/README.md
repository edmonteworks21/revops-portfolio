# Salesforce Admin

Hands-on Salesforce administration work, built in my own
Developer Edition org.

## What's in this org

- 200 leads loaded via the Data Import Wizard, spread across
  10 lead sources, 10 industries, and three company-size tiers
- Sample accounts, contacts, and opportunities

## Why the data is synthetic

Real CRM data can't be shared publicly. This data was
generated to be realistic enough that reports and dashboards
show actual patterns rather than noise.
